# 제품 요구사항

설계 논의 중인 초안입니다. 확정 사항과 미정 사항을 구분하며 코드 수준의 상세 설계는 작성하지 않습니다.

## 목적과 기본 방향

- 급여 시각화를 통해 노동의 동기를 제공합니다.
- 핵심 사용자는 노동하며 급여를 받는 노동자와 직장인입니다.
- 근무 중 휴대폰을 잠깐 보았을 때 금액이 계속 오르는 경험을 제공합니다.
- 근태 관리나 급여 관리 기능을 목적으로 하지 않습니다.
- 일본에 출시하며 앱 UI 문구는 일본어로 작성합니다.
- 플랫폼별 네이티브 언어로 개발하며 서버는 사용하지 않습니다.

## 확정된 핵심 동작

- 사용자가 월급 액수와 월급날을 설정합니다.
- 메인 화면은 이번 달 쌓인 금액을 표시합니다.
- 앱 화면의 금액은 0.1초마다 증가합니다.
- 설정한 월급날 0시에 표시 금액이 설정한 월급 액수에 도달합니다.
- 월급날에 알림을 제공하고, 앱을 켰을 때 돈이 터지는 축하 애니메이션을 표시합니다.

## 논의가 필요한 사항

- 누적 기간: 달력상 월초부터 월급날까지인지, 이전 월급날부터 다음 월급날까지인지
- 금액 증가 조건: 하루 종일 증가할지, 설정한 근무 시간에만 증가할지
- 월급 도달 이후 새 누적을 시작하는 시점과 축하 화면에서 월급을 보여 주는 방식
- 서버 없는 구조에서의 기기 내 알림 사용 여부와 알림 권한이 없는 경우의 동작
- 축하 애니메이션의 표시 시점, 반복 여부 및 월급날 이후 앱을 처음 열었을 때의 처리
- 월급날이 해당 월에 없는 경우의 처리와 기준 시간대
- 월급 액수 또는 월급날 변경 시 누적 금액 처리
- 첫 출시 지원 플랫폼·기기와 최소 OS 버전
- 위젯·스마트 워치의 표시 방식과 갱신 주기(TASK-001)
