# 제품 요구사항

설계 논의 중인 초안입니다. 확정 사항과 미정 사항을 구분하며 코드 수준의 상세 설계는 작성하지 않습니다.

## 목적과 기본 방향

- 급여 시각화를 통해 노동의 동기를 제공합니다.
- 핵심 사용자는 노동하며 급여를 받는 노동자와 직장인입니다.
- 근무 중 휴대폰을 잠깐 보았을 때 금액이 계속 오르는 경험을 제공합니다.
- 근태 관리나 급여 관리 기능을 목적으로 하지 않습니다.
- 일본에 출시하며 앱 UI 문구는 일본어로 작성합니다.
- 플랫폼별 네이티브 언어로 개발하며 서버는 사용하지 않습니다.

## 확정된 핵심 동작

- 사용자가 월급 액수와 월급날을 설정합니다.
- 메인 화면은 이번 달 쌓인 금액을 표시합니다.
- 누적 기간은 이전 월급날 0시부터 다음 월급날 0시까지입니다. 여기서 이번 달 쌓인 금액은 해당 월급 주기에 쌓인 금액을 의미합니다.
- 금액은 근무 시간과 관계없이 하루 24시간 계속 증가합니다.
- 월급 액수를 해당 월급 주기의 전체 시간으로 나누어 일정한 속도로 누적 금액을 계산합니다. 월별 주기 길이가 달라도 다음 월급날 0시에 월급 액수에 도달합니다.
- 앱 화면은 누적 금액을 0.1초마다 갱신하며, 금액은 소수점 없이 엔 단위로 표시합니다. 표시 숫자는 정수 금액이 바뀔 때 변하므로 매 갱신마다 증가하지 않을 수 있습니다.
- 표시 금액의 소수 부분은 버립니다. 예를 들어 123.9엔은 123엔으로 표시합니다.
- 설정한 월급날 0시에 표시 금액이 설정한 월급 액수에 도달합니다.
- 월급날에 알림을 제공하고, 앱을 켰을 때 돈이 터지는 축하 애니메이션을 표시합니다.
- 월급날 0시에 직전 주기의 누적을 마치고 새 주기의 금액을 0원부터 누적합니다.
- 월급날 이후 처음 앱을 열면 직전 주기의 월급 액수와 돈이 터지는 축하 애니메이션을 보여 줍니다.
- 축하 연출이 끝나면 새 주기에 쌓인 금액을 표시합니다.
- 축하 애니메이션은 월급 주기마다 한 번 표시합니다.

## 논의가 필요한 사항

- 서버 없는 구조에서의 기기 내 알림 사용 여부와 알림 권한이 없는 경우의 동작
- 여러 월급 주기 동안 앱을 열지 않은 경우의 축하 애니메이션 처리
- 월급날이 해당 월에 없는 경우의 처리와 기준 시간대
- 월급 액수 또는 월급날 변경 시 누적 금액 처리
- 첫 출시 지원 플랫폼·기기와 최소 OS 버전
- 위젯·스마트 워치의 표시 방식과 갱신 주기(TASK-001)
