# money-see

월급이 조금씩 증가하는 모습을 시각화하여 노동의 동기를 제공하는 앱입니다.

## 프로젝트 소개

사용자가 월급 액수를 입력하면 앱 화면에 금액이 증가하는 애니메이션을 표시합니다. 일하는 중 휴대폰을 잠깐 보았을 때 금액이 계속 오르는 것을 느끼는 경험이 서비스의 핵심입니다.

money-see는 근태 관리나 급여 관리 앱이 아닌, 급여 시각화를 통한 동기부여 앱입니다. 핵심 사용자는 노동하며 급여를 받는 노동자와 직장인이며, 특히 노동이나 근무의 따분함으로 동기가 부족한 사람입니다.

## 핵심 경험

- 사용자가 자신의 월급 액수를 입력합니다.
- 앱 화면에서 0.1~1초마다 금액이 증가하는 애니메이션을 보여 줍니다.
- 사용자는 근무 중 잠깐 화면을 확인하여 금액이 오르는 모습을 볼 수 있습니다.

이는 구현할 핵심 요구사항이며, 현재 구현 완료된 기능을 의미하지 않습니다. 급여 증가 계산 방식은 설계 단계에서 확정합니다.

## 개발 방향

- Kotlin, Swift 등 플랫폼별 네이티브 언어로 개발합니다.
- iOS와 Android를 하나의 저장소에서 관리합니다. 플랫폼별 소스와 빌드 설정은 분리합니다.
- 서버는 사용하지 않습니다.
- 1인 개발과 AI Agent를 활용한 개발로 진행합니다.

## 지원 대상과 언어

- 모바일, 태블릿, 위젯, 스마트 워치를 지원 대상으로 고려합니다.
- 앱 출시 국가는 일본이며, 사용자에게 표시되는 UI 문구는 일본어로 작성합니다.
- 프로젝트 문서, 코드 주석과 개발 관련 설명은 한국어로 작성합니다.
- 위젯·스마트 워치의 표시 방식과 갱신 주기는 플랫폼 제약을 확인한 뒤 설계 단계에서 결정합니다.

## 현재 개발 상태

개발 초기 단계로, 개발 운영 지침을 정리했습니다. 지원 OS와 최소 버전, 급여 증가 계산 방식, 플랫폼별 프로젝트 구성과 개발 도구 버전은 아직 확정하지 않았습니다.

진행 중인 작업과 다음 작업, 완료 이력은 [TASK.md](TASK.md)에서 확인합니다.

## 개발 환경과 실행 방법

플랫폼별 프로젝트 구성 후 작성 예정입니다. 필요한 개발 도구, 버전, 빌드·테스트 및 실행 절차는 실제 구성에 맞춰 기록합니다.
